# 三角洲枪械改枪码管理系统

一个类似飞书云文档风格的 Streamlit 应用，用于管理三角洲行动游戏中的枪械改枪码。

## 功能特性

### 🔐 用户认证
- 登录/注册功能
- 用户角色管理（管理员/普通用户）
- 会话状态保持

### 📁 文档式界面
- 飞书云文档风格的左侧导航
- 分类 → 枪械 → 改枪码 三级结构
- 面包屑导航
- 卡片式文档列表

### 🔫 改枪码管理
- 按枪械分类管理（突击步枪、冲锋枪、狙击枪等）
- 每把枪支持多套改枪方案
- 配件配置详情展示
- 标签系统
- 搜索功能

### ✏️ 编辑功能
- 添加/编辑/删除改枪码
- 添加枪械和分类
- 配件配置自定义
- 标签管理

## 快速开始

### 安装依赖

```bash
pip install streamlit
```

### 运行应用

```bash
streamlit run app.py
```

## 项目结构

```
.
├── app.py              # 主应用入口

├── data/
│   ├── users.json      # 用户数据
│   └── gun_codes.json  # 枪械改枪码数据

```

## 使用说明

1. **注册**：首次使用请注册新账号
2. **浏览分类**：左侧导航栏查看枪械分类
3. **查看枪械**：点击分类查看该分类下的枪械
4. **查看改枪码**：点击枪械查看所有改枪方案
5. **添加改枪码**：点击「添加改枪码」按钮创建新方案
6. **编辑/删除**：在改枪码详情页可以编辑或删除
7. **搜索**：在左侧搜索框搜索改枪码

## 数据存储

所有数据以 JSON 格式存储在 `data/` 目录下：
- `users.json` - 用户账号信息
- `gun_codes.json` - 枪械和改枪码数据

## 技术栈

- Python 3.13+
- Streamlit 1.51+
- 纯前端 CSS 样式（飞书风格）
